# Customer Churn Prediction & Retention Analytics

## 📌 Overview
This project predicts customer churn using Machine Learning and provides actionable retention strategies.

## 🚀 Features
- Data Cleaning & EDA
- Logistic Regression & Random Forest
- Feature Importance Analysis
- Retention Analytics (High-risk customers)
- Streamlit Dashboard

## 📊 Dataset
IBM Telco Customer Churn Dataset (~7000 customers)

## 🧠 Models Used
- Logistic Regression
- Random Forest (Best Model)

## 📈 Results
Achieved ~80% accuracy with Random Forest.

## 🎯 Key Insights
- Month-to-month contracts → high churn
- High monthly charges → churn
- Low tenure → churn

## 💡 Retention Strategies
- Offer long-term plans
- Improve onboarding
- Provide better customer support

## 🛠️ Tech Stack
Python, Pandas, Scikit-learn, Streamlit
